# Kids Furniture Kenya

A customer-facing storefront for Kids Furniture Kenya, built with Next.js.

## First release
- Responsive homepage using the existing red, blue and orange brand palette.
- Furniture collection with category filters.
- Product enquiry form that prepares a WhatsApp message.
- Clear paths for custom furniture enquiries.

## Run locally
1. Install Node.js (LTS).
2. Run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Before launch
- Replace temporary editorial photography with approved Kids Furniture Kenya product photos.
- Add the original high-resolution logo file.
- Add the business WhatsApp number and contact details.
- Confirm actual product names, dimensions, materials, prices and delivery coverage.
- Connect enquiries to a business-owned inbox/CRM and add persistent product data.
- Configure hosting, domain, analytics, privacy notice and production checks.

Product names and imagery in this initial design are presentation placeholders, not a verified stock list.
